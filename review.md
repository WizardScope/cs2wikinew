## 1. Задания для взаимной проверки

### Задание 1 — проверка навигации

Открыть README и перейти по ссылкам README → sources → knowledge → review. Проверить, что все страницы открываются и ссылки возвращают пользователя к нужному разделу.

**Ожидаемый результат:** все ссылки работают.

### Задание 2 — проверка актуализации знаний

На странице knowledge найти раздел «Актуализация знаний: A → B» и проверить:

1. описано ли условие A;
2. описано ли условие B;
3. рассмотрено ли влияние на K1;
4. рассмотрено ли влияние на K2;
5. рассмотрено ли влияние на K3;
6. указано ли, какие знания нужно изменить.

**Ожидаемый результат:** изменение условия приводит к понятному анализу всех трёх знаний.
