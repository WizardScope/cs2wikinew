## 1. Правила и условия применения

В рамках базы знаний рассматривается атака террористов на точку A карты Mirage в режиме Competitive 5×5.

Основные типы гранат:
- Smoke Grenade — ограничивает видимость и позволяет безопаснее пересекать открытые участки;
- Flashbang — временно ослепляет игроков в зоне действия;
- Molotov — создаёт область огня и ограничивает опасную позицию или проход.

Официальный материал Valve описывает smoke как динамический объект, взаимодействующий с окружающей средой, выстрелами и взрывами.

## 2. Источники

### S1 — официальный источник

**Тип:** правило / официальный источник.

**Источник:** Valve, официальный сайт Counter-Strike 2.

**Что проверяем:** базовые свойства дымовых гранат и их взаимодействие с игровыми событиями.

**Используется для:** K1 и K2.

### S2 — практический источник

**Тип:** объяснение / практический опыт.

**Источник:** CSDB — практические lineups для Mirage.

Практические схемы A-execute используют комбинацию smoke и flash для ограничения линий обзора и подготовки выхода.

**Используется для:** K1, K2 и K3.

## 3. Сравнение источников

| Критерий | S1 | S2 |
|---|---|---|
| Тип | Официальный | Практический |
| Назначение | Описывает механику CS2 | Показывает применение на Mirage |
| Надёжность для механики | Высокая | Средняя/высокая |
| Полезность для практики | Средняя | Высокая |

### Вывод

S1 используется для проверки игровых механик. S2 — для объяснения практического применения этих механик на Mirage.
