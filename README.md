# Counter-Strike 2: база знаний по гранатам на Mirage

## О лабораторной работе

База знаний посвящена использованию гранат при атаке точки A на карте Mirage в Counter-Strike 2.

**Игра:** Counter-Strike 2  
**Карта:** Mirage  
**Режим:** Competitive 5×5  
**Сторона:** Terrorists  
**Тема:** Использование гранат при атаке точки A  
**Версия:** актуальная версия Counter-Strike 2 на момент выполнения лабораторной работы  
**Автор:** Михаил Монжаренко  
**Дата:** 09.09.2026

## Для кого эта база знаний

Материал предназначен для нового игрока CS2, который уже знает основные элементы управления и умеет стрелять, но испытывает сложности с использованием гранат при выходе террористов на точку A Mirage.

## Задачи читателя

1. Понять, какую роль играют основные гранаты при выходе террористов на точку A Mirage.
2. Научиться выбирать гранату и последовательность её использования в зависимости от ситуации на точке.

## Содержание знаний

- **K1** — зачем использовать дымовую гранату при выходе на A;
- **K2** — как выбрать между smoke и flash в зависимости от позиции защитников;
- **K3** — как избежать типичной ошибки с ослеплением собственного игрока.

База также содержит анализ зависимостей между знаниями и пример актуализации знаний при изменении игрового условия A → B.
